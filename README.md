# Финансовые новости — анализ тональности

Учебный NLP-проект на семь дней: загрузка данных, EDA, очистка, baseline, улучшения, анализ ошибок и предсказания новых новостей.
Три класса: **negative (0), neutral (1), positive (2)**.

Весь код и подробный README находятся в [financial_sentiment.ipynb](financial_sentiment.ipynb), Дни 1–7. Графики, таблицы и выполненные результаты сохранены внутри ноутбука.

## Файлы

- `financial_sentiment.ipynb` — весь проект в одном ноутбуке.
- `models/best_model.pkl` — обученный LinearSVC.
- `models/vectorizer.pkl` — обученный TF-IDF.
- `requirements.txt` — проверенные версии зависимостей.

## Запуск

Проверено на Python 3.13.5. Откройте папку репозитория `nlp` в VS Code с расширениями Python и Jupyter.

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Выберите `.venv` как Python-ядро ноутбука. Рабочая папка ядра должна содержать `financial_sentiment.ipynb`.

**Обучение с нуля:** Restart Kernel and Run All. Нужен интернет для скачивания датасета. Дни 1–5 подготовят данные, обучат и сравнят модели; День 6 создаст файлы в `models`; День 7 покажет итоговые проверки.

**Только предсказания:** сохранённые модели уже входят в репозиторий. После перезапуска ядра выполните:

1. День 1 — ячейку импортов с `import hashlib`, без загрузки данных.
2. День 2 — ячейку с `import html` и функцией `clean_text`.
3. День 6 — раздел 2, загрузку через `joblib.load`.
4. День 6 — раздел 3, определение `predict_sentiment`.
5. День 6 — demo-ячейку раздела 4 либо вызов:

```python
predict_sentiment(
    "Operating profit increased by 25%.",
    loaded_model,
    loaded_vectorizer,
)
```

Функция принимает строку или непустой список строк, применяет ту же очистку и возвращает таблицу `text`, `text_clean`, `label`, `sentiment`. Интернет и обучение для inference не нужны. LinearSVC не выдаёт вероятности классов.

## Данные

[Financial PhraseBank](https://huggingface.co/datasets/takala/financial_phrasebank), файл `Sentences_50Agree.txt`.
Авторы: Pekka Malo, Ankur Sinha, Pekka Korhonen, Jyrki Wallenius, Pyry Takala. [Статья](https://arxiv.org/abs/1307.5336).
Лицензия данных: [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/).
Версия `8d3fe0c36d5feec6b3cc5e455b0fcb4820fb9964` и SHA-256 архива зафиксированы в ноутбуке.

Исходных строк — 4 846, после удаления дубликатов и конфликтующих меток — 4 836.
Train/test — 3 868/968 (80/20, стратификация, random_state=42).
TF-IDF обучается только на train. Подбор C выполнен по трёхкратной кросс-валидации внутри train.

## Результаты на одном test

| Метод | Macro F1 |
|---|---:|
| Baseline TF-IDF (1, 2) + Logistic Regression | 0.6918 |
| TF-IDF (1, 3) + Logistic Regression | 0.6948 |
| TF-IDF (1, 2) + LinearSVC | **0.7252** |
| TF-IDF (1, 2) + Logistic Regression, подбор C | 0.7146 |

Лучший вариант: **TF-IDF (1, 2) + LinearSVC**, accuracy **0.7727**.
Относительный прирост macro F1 — **4.83%**; цель общего задания +5% пока не достигнута.

Ошибок — 220 из 968. Чаще всего positive принимается за neutral (95 случаев).
В Дне 5 сохранены confusion matrix, примеры каждого класса и подробный разбор семи ошибок.
В Днях 6–7 есть пять новых demo-новостей; в одном случае модель ошибается относительно учебного ожидания.

## Ограничения и проверка

Модель предназначена для английских финансовых предложений. Она ограниченно понимает числовые сравнения, планы и контекст; классы несбалансированы, метки могут быть неоднозначными.
Test использован для сравнения и выбора модели, поэтому независимая оценка после выбора победителя не проводилась.
Тональность новости не является прогнозом цены или готовым торговым сигналом.

Полный ноутбук проверен в чистой копии проекта. Inference дополнительно проверен в новом Python-процессе с заблокированными сетью и методами обучения. Версии окружения перечислены в requirements.txt и Дне 7.
